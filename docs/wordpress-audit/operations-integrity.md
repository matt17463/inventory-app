## Verified findings requiring operating attention

1. **Installed/repository version drift.** Client Storefronts installed header is 0.1.2; repository companion is 0.1.3. The installed QA draft preview works. Compare actual deployed code in a separately authorized maintenance task before assuming which behavior differs. Do not update a live plugin as an audit shortcut.
2. **Legacy/native personalization coexist.** SC Product Options is in Replacement mode, with legacy reading enabled. Both administrator checklist boxes are checked; override and debug logging are unchecked. The screen reports parity MATCH and readiness YES. Those are pre-existing configuration/status claims, not this auditor validating pricing and checkout. Legacy Product Add-Ons remains active and its row reports a subscription/update issue. Preserve legacy historical metadata and review representative products before any cutover change.
3. **Shipping has multiple layers.** Kitsap County core free shipping is enabled and uses minimum order amount OR coupon, with 200.00 minimum and pre-discount qualification unchecked. Core flat rate is enabled, base 0.00, taxable, with per-order highest-class calculation and nonzero class/no-class costs. A separate Advanced Free Shipping rule titled “Spend $200 get free shipping!” also exists. Do not diagnose a customer rate from only one layer or treat the local-zone values as universal.
4. **Sync and relink are distinct.** The live sync help recommends linking unchecked and bounded batches, then a separate blank-master relink. The repair tool can create blank records, not just diagnose them. A product being visible in Supabase does not establish correct pull-sheet pairing.
5. **Generation is not physical printing.** Print Documents has generation logging and auto-open print dialog set to Yes. Its own help says browsers cannot reliably report physical print success. Never use a generation event as a packing/QC/dispatch signoff.
6. **Several SKU writers are active.** Resolve ownership before regenerating identifiers. SKU Builder says it deliberately does not sync Supabase during rebuilding. Downstream links must be reconciled separately; this audit did not do so.
7. **Navigation has two directory paths.** Homepage uses `/shop-new/`; Team Orders links to `/find-your-store/`. The former search and no-match state were verified. Alias consistency remains open, rather than assumed broken.
8. **Form labels need review.** The public artwork form contains “subject / Preferred” and some spelling/capitalization inconsistencies. Their intended mapping is unknown. An unlabeled field was not incorporated into novice instructions; do not assume it is a customer-facing requirement or remove a possible anti-spam field without inspecting form configuration.
