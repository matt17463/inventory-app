# Release Notes — 0.6.22

## Graphically distinct interface themes

Version 0.6.22 rebuilds the theme presets so they change the application’s
complete visual language rather than primarily changing colors.

### Included interface styles

1. **Technical Blueprint**
   - Drafting grids
   - Monospace headings
   - Bracketed and chamfered controls
   - Indexed labels and technical corner marks

2. **Futuristic Interface**
   - Glass panels
   - Luminous gradients
   - Orbital background graphics
   - Floating depth and pill controls

3. **Cyberpunk Neon**
   - Cyan and magenta glow
   - Scan-line overlay
   - Clipped corners
   - Signal labels and high-energy typography

4. **Formal Executive**
   - Serif headings
   - Navy and gold details
   - Fine rules and paper-like surfaces
   - Restrained formal controls

5. **Professional Enterprise**
   - Crisp corporate cards
   - Practical control geometry
   - Clear hierarchy
   - Data-first table treatment

6. **Industrial Command**
   - Steel surfaces
   - Hazard-stripe accents
   - Rivet details
   - Heavy production-floor controls

### Compatibility

Preferences saved by version 0.6.21 are automatically mapped to the closest
new style. Light, dark, system mode, density, help-panel, and reduced-motion
preferences continue to work.

### Scope

This release changes visual files only. It does not modify inventory,
pull-sheet, purchasing, purchase-order, WooCommerce, Supabase, Netlify
function, route, permission, or SQL behavior.

No SQL migration is required.
