# Release Notes — v0.6.28

## Workflow proximity and reduced scrolling

Version 0.6.28 is a layout/usability release built on the complete v0.6.27 codebase.

### Changed

- Existing Manual Invoiced Orders edit beneath the selected order row.
- Individual blank products edit beneath the selected product row.
- Pricing Rules, Non-Inventory Rules, and Job Costing edit beneath selected rows.
- Blank-product bulk editing appears after the result table.
- Multi-pull-sheet due-date controls appear after the pull-sheet table.
- Production time-rule loading no longer forces a page-top jump.
- Shared page density reduces header, panel, field, table, and navigation height.
- Inline editors clearly highlight their parent row and include sticky save/cancel actions where appropriate.
- Mobile layouts receive compact inline-editor spacing.

### Preserved

All v0.6.27 search improvements and the v0.6.23–v0.6.26 pull-sheet and non-inventory safety fixes remain included.

### Database

No Supabase SQL migration is required.
